Complete Order Graphs: Best Known Sizes

An order graph of dimension d has attribute orders (permutations of 1,…,d) as nodes, and an edge labeled a from each order π to the order a·π obtained by moving a to the front. It is complete if, for every set S of attributes and every x ∉ S, some path is labeled exactly by S ∪ {x}, with x at one end (bidirectional model) or at the end (unidirectional model). Complete order graphs give indexes that support worst-case optimal joins in every attribute order; their number of edges is the space of the index. This page tracks the smallest complete order graphs known.

Background and lower bounds: R. Becker, A. Gómez-Brandón, G. Navarro, and N. Prezza. Tight Asymptotic Bounds on the Size of Order Graphs. arXiv, 2026.

Graph format

Each graph can be downloaded as an edge list: one edge per line, written as the source order and the label, e.g. 412563 6 (the target is the order with the label moved to the front). Graphs with d ≤ 9 are also shown in a compact format, one line per weakly connected component: a start order, then a bracketed list of edges. A digit a is an edge labeled a from the current node to a·π, where π is the current order, and the brackets that follow it list the edges leaving that target; a star marks an edge whose target already appeared. This Python function lists the edges of a component:

def edges(start, s):
    out, stack, cur = [], [], start
    for c in s:
        if c.isdigit():
            last = c + cur.replace(c, "")
            out.append((cur, c, last))
        elif c == "[":
            stack.append(cur)
            cur = last
        elif c == "]":
            cur = stack.pop()
    return out
